这一篇就是一个简短的资源分享，没有太多实际内容，分享一下我最近浏览到的很炫酷的网站组件资源。

## CanvasUI-实验性产品

<WebsiteCard
  url="https://canvasui.dev/"
  title="Canvas UI"
  description="依赖Chrome的HTML-in-Canvas这个实验功能的组件库"
/>

这是一个有着比较新技术组件库，它使用了比较新的 HTML-in-Canvas 能力，让 DOM/HTML 内容可以参与 Canvas 中的渲染和视觉变换。目前这仍属于比较新的浏览器能力，浏览器兼容性需要特别注意。好在 Canvas UI 本身考虑了 fallback，在不支持相关能力的环境下也可以提供降级方案。

尤其适合需要 3D、液态、玻璃、破碎等复杂视觉效果的网页，可以去看下网页提供的预览效果，然后决定是否是自己想要的效果。

## React Bits-特殊效果

<WebsiteCard
  url="https://reactbits.dev/"
  title="React Bits"
  description="一些React的特效小组件"
/>

一个以 React 为核心的特效组件集合，同时提供 JavaScript / TypeScript、CSS / Tailwind 等不同实现方式。里面有着各种各样的炫酷效果，大部分专注于文字特效和背景交互特效。主要以比较特殊的视觉效果为主，可以多从中吸取些经验和灵感。

## Aceternity-务实落地

<WebsiteCard
  url="https://ui.aceternity.com/"
  title="Aceternity"
  description="依旧一些React的小组件，但是主要比较务实"
/>

依旧是一个 React 的组件库，但整体风格比较务实，方便使用，且风格适用广。

虽然有付费使用的 template 效果也还不错，但是免费的权限就很够用了，我个人认为付费的那些 template 其实直接交给现在的ai去做效果不一定会更差，反而可能会很贴合你的需求，很适合去探索探索，获取些交互和设计上的灵感。

## Motion-自己设计动画

<WebsiteCard
  url="https://motion.dev/"
  title="Motion"
  description="支持JS，React和Vue的动画效果库"
/>

Motion 更准确来说是一个动画库，而不是传统意义上的 UI 组件库。它提供了 JavaScript、React、Vue 等环境下的动画能力，可以用来处理页面过渡、手势、布局变化以及各种交互动画。

我的网站就用了些motion的效果，用起来还是很不错的。如果你不只是想“找一个现成组件”，而是希望自己控制动画，那么 Motion 比单纯的组件库更值得研究，可以多去探索探索。

## anime JS-动画字典

<WebsiteCard
  url="https://animejs.com/"
  title="anime JS"
  description="支持原生JS和React的动画效果库"
/>

这个网站本身就炫酷的不行，是一个主要注重动画效果的网页库，里面有着各种各样的动画曲线，也有着很多交互元素的设计效果。

你可以用它控制 DOM、SVG、CSS 属性等各种对象的动画，非常适合拿来研究各种动画节奏、缓动和交互方式。可以作为一个动画效果的字典去使用，十分推荐任何想要去学习设计的同学去学习。

## Animate UI-微量调整

<WebsiteCard
  url="https://animate-ui.com/"
  title="animate-ui"
  description="依旧是一个React的组件库"
/>

Animate UI 的组件数量相比前面的几个库少一些，但它比较值得看的地方是微交互，尤其是 Icon、Button 等组件的动画。对于已经有完整 UI，只是觉得页面“有点死”的项目来说，这类效果反而比较实用。

## Inspira UI-专注Vue的组件库

<WebsiteCard
  url="https://inspira-ui.com/"
  title="Inspira UI"
  description="终于，一个专门服务于Vue和Nuxt架构的动画库"
/>

上面的全都是 React 的组件库，那我们 Vue 用户吃什么？

哈哈哈，这不就来了？

这是一个主要服务于 Vue 和 Nuxt 架构的动画库，效果也很全面，从简单的 ui 到全局的特效都有，里面的大部分内容已经足够对齐上方提到的 React 的组件库了。

不过这里也不意味着 Vue 用户只能使用 Vue 的组件库。React 组件本身当然不能直接复制进 Vue 项目，但很多视觉效果实际上并不依赖 React 本身，尤其是 CSS、SVG、Canvas 和普通 JavaScript 实现的效果。现在有了 AI，把一个 React 组件改写成 Vue 版本通常已经比以前简单很多，所以我自己找组件的时候也不会特别在意它到底是 React 还是 Vue。

## 写在最后

以前看到一个很酷的效果，通常意味着你需要把它的代码研究一遍，再想办法塞进自己的项目里。现在有了AI，完全是两个世界了，要简单很多：**先找到自己喜欢的效果，再把组件的实现方式、依赖和自己的需求告诉 AI，让它帮你修改，已经变成了一个非常实用的工作流。**

所以我现在逛这些网站的时候，已经不太会把它们单纯当成“组件库”了。很多时候我只是去找一个我喜欢的视觉效果，然后自己重新实现。

组件库负责提供灵感和参考，AI 负责帮你把它变成适合自己网站的东西。

上面推荐了很多动画效果的组件库，但是对于一个网页来说，最重要的不是看起来有多么炫酷，而是使用起来符不符合用户直觉，用户的体验是不是流畅。一个上手门槛、设备门槛合理的网站才是最好的网站。

**动画应该帮助用户理解页面的结构、状态和反馈，而不是让用户为了看动画而等待。过多的视觉效果不仅可能影响信息获取，也会增加性能和设备方面的负担。**
